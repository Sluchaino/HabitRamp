# HabitRamp

Офлайн-приложение для развития привычек на Android. Работает полностью локально:
без аккаунтов, сервера, синхронизации и ИИ. Все данные хранятся на устройстве и
переживают перезапуск приложения и изменение системных часов.

## Возможности

- Постепенный рост цели по формуле `Цель = База + Шаг × (2 × Цикл + День)`.
- Циклы выполнения, настраиваемая длина цикла и ежедневный шаг.
- Целевое значение с выбором поведения при достижении (поддерживать / завершить / спросить).
- Политики обработки пропусков (сохранить цель / уменьшить на штраф).
- Ручной сброс нагрузки на 50 % (применяется сразу или откладывается до следующего
  запланированного дня).
- Паузы на неделю или месяц с уменьшением цели по завершении.
- Расписание по дням недели и постепенная разблокировка слотов привычек.
- Статистика: фактические и потенциальные значения, сравнение с предыдущим периодом.
- История в виде календаря с отметками выполнения, частичного выполнения, пропусков,
  пауз и сбросов.
- Локальные напоминания (AlarmManager + WorkManager), восстановление после
  перезагрузки и смены часового пояса.
- Архивация, завершение и удаление привычек.

## Стек

- Kotlin 2.1.21, Jetpack Compose (Material 3)
- Room 2.7.1 (KSP), DataStore Preferences
- ViewModel + StateFlow, Navigation Compose
- WorkManager, AlarmManager, BroadcastReceiver
- JUnit 4 для модульных тестов

## Сборка

Требования: JDK 17, Android SDK с платформой 36.

```powershell
$env:JAVA_HOME="$env:USERPROFILE\.jdks\temurin-17"
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённое устройство:

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## Архитектура

```
core/        модели, единицы измерения, точные десятичные числа, даты, уведомления
domain/      доменные модели и чистые калькуляторы (без Android)
data/        Room-сущности, DAO, мапперы, репозиторий, DataStore
presentation/ экраны и ViewModel'и (Compose)
```

Ключевые решения:

- Доменные расчёты вынесены в `domain/calculator` и не зависят от UI и Android.
- Деньги и измерения хранятся как точные десятичные строки (`BigDecimal`),
  `Double` не используется как основное хранилище.
- Даты хранятся как epoch-day (`Long`), конец паузы — исключающая дата.
- На каждую привычку и дату допускается ровно одна запись (уникальный индекс),
  повторные нажатия идемпотентны.
- Догоняющая обработка (`runDailyProcessing`) выполняется при старте, при изменениях
  и раз в сутки через `DailyMaintenanceWorker`.
- Отложенные ручные сбросы применяются автоматически, когда наступает их дата.

## Тесты

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

Покрыты калькуляторы прогрессии, пропусков, пауз, сбросов, разблокировки слотов и
статистики, работа с датами и десятичными числами, мапперы Room и округление
фактических значений.

Интеграционные тесты Room и репозитория требуют запущенного эмулятора или устройства:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

Они проверяют идемпотентность выполнения, отложенные сбросы, несколько пропущенных
дней подряд, паузы и уведомления, перевод часов, сохранение прогресса после
перезапуска, архивацию/завершение, несколько привычек и изменение расписания.
